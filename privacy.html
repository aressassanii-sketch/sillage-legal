Politique de confidentialité — Sillage

Dernière mise à jour : 26 mai 2026 | Développeur : Aress Assani

1. Collecte des données

Sillage collecte uniquement les données nécessaires au fonctionnement de l'application :

  • Données de santé : poids, composition corporelle, séances d'entraînement, données nutritionnelles — stockées localement sur votre appareil via SwiftData et synchronisées avec iCloud si activé.
  • Données de compte : adresse e-mail et identifiant Apple lors de l'inscription (Sign in with Apple).
  • Données d'utilisation : statistiques anonymisées d'utilisation pour améliorer l'app (optionnel).

2. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Fournir les fonctionnalités de suivi sportif et nutritionnel
  • Générer des conseils personnalisés via l'IA (API Anthropic, sans partage des données personnelles)
  • Synchroniser vos données entre vos appareils Apple via iCloud (optionnel)

3. Partage des données

Vos données personnelles ne sont jamais vendues ni partagées avec des tiers. Les appels à l'API Anthropic (coach IA) sont effectués de manière anonymisée — aucune donnée identifiable n'est transmise.

4. Stockage et sécurité

  • Toutes les données sont chiffrées sur l'appareil
  • La clé API Anthropic est stockée exclusivement dans le Keychain iOS sécurisé
  • Aucun serveur tiers ne stocke vos données de santé

5. HealthKit

Sillage peut lire et écrire des données dans HealthKit (poids, calories, séances) avec votre autorisation explicite. Ces données ne quittent jamais votre appareil Apple.

6. Droits des utilisateurs

Vous pouvez à tout moment :

  • Supprimer toutes vos données depuis Réglages → Supprimer le compte
  • Désactiver la synchronisation iCloud
  • Révoquer l'accès HealthKit dans Réglages iOS → Santé

7. Contact

Pour toute question : aress.assani.i@gmail.com

8. Modifications

Cette politique peut être mise à jour. Les modifications importantes seront notifiées dans l'application.
